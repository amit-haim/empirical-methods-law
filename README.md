## Data source · מקור הנתונים

The data are the case-centered file of the **Israeli Supreme Court Database (ISCD)**: all final decisions of the Israeli Supreme Court given by panels of three or more justices. One row is one case.

Weinshall, Keren, Lee Epstein & Andy Worms. *The Israeli Supreme Court Database*, 2018 version. <http://iscd.huji.ac.il>

Full codebook: <https://web.archive.org/web/20221206211948/https://iscd.huji.ac.il/documentation>
